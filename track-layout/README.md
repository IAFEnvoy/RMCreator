# 配线工坊

独立的纯前端平面配线编辑器，入口为 `/track-layout/`。线路只绘制矢量线条，站台绘制为可编辑色块。与线路图、车站设计器共用导航和主题，作品库独立。

- **折线 L**：逐点点击，双击放置终点并完成，也可按 Enter 完成。Shift 约束水平、垂直和 45°；Shift 双击完成后可继续绘制下一条。
- **曲线 C**：起点 → 控制点 → 终点，继续控制点 → 终点；绘制时可切换 L / C 混合直线和曲线。Backspace 回退，Esc 取消。
- **站台 R**：拉框，或点击两个对角点。可修改尺寸、旋转角度、圆角、填色和边框。
- **文字 T**：输入文字后点击放置。可修改颜色、字号、角度与位置。
- **选择 V**：拖动对象、顶点或曲线控制点。双击线段插入顶点，右侧可调整坐标或切换线段类型。
- **线型**：实线、虚线、点线和存车线；左侧设置新线条，右侧修改已选线条，也可批量修改。存车线终点自动显示同色挡车横线，随曲线切线转向；用“反转路径”切换尽端所在的一头。预览、SVG / PNG 和 JSON 均保留此线型。
- **渐变**：线条颜色可选纯色或渐变，设置起点色与终点色；渐变方向跟随路径首尾，移动与编辑顶点后自动更新。实线、虚线、点线和存车线均可使用，导出 SVG / PNG 与画布一致。高增站的顶部虚线联络为一条可编辑渐变曲线；已有图纸中未修改的旧版八段虚线会自动合并，修改过的片段保留。
- **吸附**：端点、线条、站台边缘和网格；从非网格起点继续绘制时保留精确坐标。水平、垂直及既有线条的平行 / 垂直方向显示参考线，接触线条时求实际交点；Shift 约束水平、垂直和 45°，Alt 临时关闭吸附。
- **多选与复制**：Shift 点击 / 框选，Ctrl+D 复制，Delete 删除。完成时按 Shift 连续放置。
- **视图**：滚轮缩放，右键拖动画布，左键选择和编辑，F 适应画布。
- **文件**：自动保存，新建、重命名、副本、回收站与 JSON 导入；导出 SVG、PNG、JSON。SVG / PNG 不包含网格和编辑手柄。

内置车站渡线与折返线、车辆基地扇形存车线、广州3、9号线高增站三个可编辑示例。首次使用默认加载“广州3、9号线 高增站”，已有方案库继续恢复上次编辑的方案；“载入示例”默认选中高增站，“新建”仍使用空白画布。“广州3、9号线 高增站”按参考图绘制两座站台、上下交叉渡线、中间轨和顶部虚线联络；独立 JSON 位于 `examples/reference-interchange.json`。车站示例的上下行共用一块连续的岛式站台。存储键见 `shared/storage-keys.js` 的 `LAYOUT_STORAGE_KEYS`。多窗口有未保存修改时阻止覆盖，并提示先导出备份。
