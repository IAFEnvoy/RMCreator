# RMCreator · 车站空间设计

纯前端地铁车站 3D 示意图设计工作台，使用 Vite、原生 JavaScript 和 Three.js。默认提供参考上海地铁导览图表达方式的双层岛式车站示例。

## 本地运行

此工具已整合到 RMCreator。从上一层项目根目录执行以下命令，启动后进入 `/station-designer/`。构建和依赖由项目根目录统一管理。

```bash
cd ..
pnpm install
pnpm dev
```

浏览器打开终端显示的地址，默认是 http://localhost:5173 。

```bash
pnpm build
pnpm preview
```

构建产物位于 `dist/`，可以部署到静态网站服务。不需要后端、数据库或 API 密钥。

## 使用

- **右侧设置**：「整体设置」集中车站名称、线路、区域面积、自动边界设施、吸附与显示开关；「对象属性」只编辑当前选中构件的名称、楼层、尺寸、位置及轨道参数。选中对象时自动切换到对象属性，切换标签页保留选择；未选中时显示选择提示。
- **场景图层**：左侧按楼层展开对象，支持搜索楼层或对象、选取、显隐及与画布选择同步。点击楼层切换当前视图，设置按钮可直接编辑名称、标高或删除楼层；面板顶部可添加楼层和调整统一层间距。画布上方保留快速选层，管理入口统一打开左侧面板。顶部选层、左侧图层和楼层下拉菜单均按实际标高从高到低排列，修改标高后立即重排；相同标高的层保持原相对顺序，并显示黄色警告，悬停可查看重复楼层。楼层设置支持修改 B1 / B2 等简写（1–10 个字符），同步更新场景、选择菜单和导出，内部楼层关联保持不变。构件自动对齐所属楼层；删除楼层会保留并迁移构件与填色。
- **钢笔区域**：保留 2 米网格作为参考。选一层，再选付费区、非付费区或员工区域，单击添加角点、按下拖动拉出平滑点，直边和曲边可混合。点击起点、双击画布或按 `Enter` 闭合，闭合后自动进入顶点编辑；`Backspace` 撤回上一点，`Esc` 取消未完成轮廓。绘制时按住 `Ctrl / Cmd` 可临时移动已有顶点与手柄，松开继续画。
- **轮廓编辑**：`A` 选点，`P` 钢笔（闭合后为加点）。顶点为空心圆，选中为实心圆，控制柄以浅色线显示。拖顶点会带着手柄移动；平滑点的两端手柄反向共线、长度独立，`Alt / Option` 拖手柄改为独立拐点。`Shift` 多选，空白处拖框选择，`Ctrl / Cmd + A` 全选；拖动时 `Shift` 约束水平、竖直或 45°。工具栏切换选点、加点、减点、转换，右侧可批量转换角点 / 平滑点 / 拐点、删除顶点或精确输入顶点和手柄坐标。曲线上加点采用 de Casteljau 拆分保持原形，删点采用保留端部切线的三次贝塞尔拟合，尽量维持原轮廓。选点后「开放路径」在该点断开（开放时不填色），「连接首尾」可重新闭合。区域可复制、删除、撤销，并纳入左侧场景图层；旧格子区域在首次进入钢笔工具时转换为等形轮廓，包含孔洞，复杂旧区域保留原数据。
- **区域吸附与填色**：顶点优先吸附已有顶点，再吸附区域 / 轨道边界和网格，绿点与提示显示吸附目标，工具栏磁铁可开关。新增区域覆盖相交的旧区域，「轮廓擦除」使用闭合轮廓挖空；开放轮廓不参加填充和自动边界。颜色仅作为填色显示，区域名称不叠加在场景中。曲边以自适应细分绘制，栏杆、屏蔽门、平面黑边、面积和 PNG 使用同一套实际轮廓。
- **区域开洞**：画布底部的独立「开洞」按钮为楼梯、扶梯、电梯等预留开口。选择操作楼层，默认点击矩形的两个对角点完成；也可切换「钢笔 · 直线 / 曲线」，按原有钢笔交互闭合任意轮廓。沿用网格、几何和参考线吸附，`Alt` 临时关闭；孔洞需与本层填色相交。孔洞穿透本层的付费区、非付费区和员工区域，后续补画填色也不会封住它，其他楼层保持独立。左侧图层中可选中孔洞、编辑顶点和手柄、复制、删除、撤销或恢复；删除孔洞会恢复下方原有填色。选中连接楼层的楼梯、扶梯或电梯，右侧「按此构件开洞」按占地在经过的上层和中间层生成独立孔洞，之后可自由调整；构件移动不自动移动这些手动孔洞。3D、分层平面、黑边、面积、自动栏杆 / 屏蔽门以及 PNG / JSON 均使用相同开洞结果。
- **放置对齐参考线**：放置物件和钢笔绘制区域时，靠近既有对象或区域的边缘、中线、同向顶点会显示蓝色参考线并精确吸附；旋转对象也支持沿自身方向参考。绘制新区域时匹配既有区域的宽度 / 长度，显示紫色等尺寸线和米数。楼梯跨层放置同时参考起点层与终点层，已点击的起点不因后续对齐移动。参考线按当前缩放以屏幕距离触发，仅供编辑，不导出或保存。按住 `Alt` 暂停对齐、几何和网格吸附，松开恢复；钢笔手柄上的 `Alt` 仍用于打断联动。
- **楼梯端点编辑**：选中已放置的楼梯或自动扶梯，拖动画布上的蓝色起点、紫色终点，另一端保持固定，长度和旋转角实时更新；支持 3D、楼层分解和分层平面。右侧「端点编辑」可分别修改两个端点的楼层及 X / Z 坐标，支持跨多层连接。拖动沿用参考线和网格吸附，`Alt` 临时关闭；坡度或长度超限时禁止提交，`Esc` 放弃本次拖动。一次拖动对应一次撤销，旧方案无需重新放置，端点辅助标记不会导出。
- **放置与吸附**：轨道、楼梯和自动扶梯先点击起点，再点击终点。楼梯和扶梯支持任意方向直线，两点分别指定不同楼层，可向上、向下或跨多层连接，长度和坡度按实际层高与两点间水平距离计算。直轨默认锁定横向或纵向，靠近已有轨道时优先精确接到目标位置。无障碍电梯通过两个对角点确定矩形井道，始终竖直连接上下层。放置时实时预览长度和角度，红色表示不能落位：轨道长度至少 2 m；楼梯坡度不超过 45°、扶梯不超过 35°；井道长宽均为 2–12 m；连接设施默认连接最近的其他楼层，可用放置栏的起点层 / 终点层选择任意不同楼层；跨越的中间层可保留开口，楼梯与扶梯只在停靠的两端楼层显示。坡度按实际层高计算，楼层分解仅改变显示。其他构件与标记仍点击落位。参考线和几何优先，未命中时吸附到 0.5 米网格。绘制直轨、曲线或平滑连接时，起终点在 3 米内优先吸附同层可见轨道的端点，其次吸附中心线，绿圈和切线提示接触位置；曲线控制点不吸附轨道。接轨吸附保留精确坐标，优先于付费区边缘吸附。未接轨时，轨道长边在距付费区边缘 3 米内自动贴齐，并显示绿色提示；在起点点击前完成边缘吸附，后续保留已选起点。右侧可关闭吸附，或点击「贴齐现有轨道」整理当前可见楼层。按 `Esc` 取消未完成的放置；切换楼层保留已选点与区域草稿；轨道和已绘制的区域在其他单层视图暂停输入，返回原层或全部楼层可继续。切换视图或工具会取消物件放置。
- **自动边界设施**：付费区与非付费区相接时自动生成栏杆，闸机处自动留出通道。付费区与轨道相接时自动生成屏蔽门，可统一选无、半高、全高，也可逐段轨道覆盖设置。填色、构件移动或隐藏后设施自动更新。
- **曲线与道岔**：放置轨道时可选「直线」「控制点曲线」「平滑连接」，切换方式保留起点、吸附连接及曲线控制点草稿；从已有轨道续画时继承所属线路和色带颜色。控制点曲线按「起点 → 控制点 → 终点」点击三次确定第一段，再按「控制点 → 终点」连续绘制下一段，共用上一段终点；轨道经过起终点，第二点只控制弯曲形状。最多 15 段，按 `Enter` 或「完成轨道」结束，`Backspace` 撤回一个点；控制点尚未配好终点时不能完成。绿色圆点为端点，橙色方点为控制点，辅助线连接控制点与端点，选中后均可拖动或编辑坐标；在控制点属性中可拆分或删除对应曲线段。旧直轨点击「编辑为曲线」即可使用此方式，已有自动平滑曲线保留原形。平滑连接仍点击两点完成，吸附既有轨道并对齐切线，用于折返线、渡线与分叉。关闭吸附可自由绘制；手动控制点曲线的端点吸附只对齐位置，弯曲形状由控制点决定。连接端点随主轨道调整，手动移动整段支线或「解除连接」后可独立编辑。所有曲线均为示意几何，不作工程道岔尺寸校验。
- **轨道色带**：每段轨道可单独开关色带、设置自定义颜色，也可恢复跟随线路颜色。色带始终位于行车方向右侧，切换正向 / 反向会同步换侧；关闭箭头仍可调整方向。旧方案的自动方向按原色带位置恢复，名称与列车的线路颜色不受自定义色带颜色影响。
- **构件与标记**：轨道、楼梯、自动扶梯、无障碍电梯、闸机、服务中心，以及出口和卫生间标记。出口只标记位置，通道使用非付费区填色。出口与卫生间使用正立标记，可设置名称、颜色、大小和所属层；出口编号可独立编辑。楼梯、扶梯采用开放底部结构，按连接高度和水平长度自动细分台阶；跨多层或楼层分解时增加台阶数量，避免固定级数导致台阶被拉大。密集台阶使用实例渲染。
- **楼梯平面显示**：楼梯与自动扶梯只在起点层、终点层各显示靠近本层端点的一半，标记居中于可见半段；跨越但不停靠的中间层不绘制模型或标记。单层视图只显示本层端点的编辑手柄，换到另一端所在层可调整另一端；全部楼层视图可同时编辑两端。台阶间距、实际连接长度及 3D 模型保留原数据，放置预览仍展示完整连接；PNG 使用相同平面显示。电梯在经过的各层保留显示。
- **轨道方向**：选中轨道，在「轨道方向与色带」中开启「显示箭头」，新轨道和未设置过的旧轨道默认关闭。行车方向可选正向（起点到终点）或反向（终点到起点），同时决定箭头朝向与色带所在侧；色带保持在行进方向右侧。平面箭头位于指向端，并跟随曲线切线、整体旋转和方向切换。箭头开关独立于色带开关，设置随方案保存并用于 PNG 导出。
- **独立文字**：从「构件库 → 文字与标注 → 文字工具」、画布底部的 `T` 按钮或快捷键 `T` 创建文字，输入内容后点击当前楼层放置。「显示方式」提供两种：贴地文字沿楼层平面显示，可任意旋转；「悬浮文字（朝向相机）」使用正立文字框，旋转或俯视时始终朝向镜头，抬升距离可调。可选「启用锚点」：开启后引线连接独立的指向位置，可在画布取点、拖动端点或输入坐标；拖动文字框时锚点保持不动。关闭后仅显示文字框，位置保持不变。可随时切换，保留内容、位置及贴地旋转角。两种方式均支持换行、字号、颜色、粗体、对齐、横排 / 竖排和反向字序；竖排逐字排列。拖动文字框可移动文字，拖动锚点可独立调整指向位置，在左侧场景图层中独立选取和显隐，也能复制、删除、撤销和切换楼层。PNG 保留文字框及启用的引线，JSON 保存显示方式、锚点开关和坐标。既有文字默认贴地，新轨道不自动添加文字。文字的位置、内容和颜色独立保存，轨道移动、旋转、改名、换色或删除均不影响文字。
- **多线路**：通过「线路管理」添加、重命名和设置各条线路颜色。每段轨道独立指定所属线路，车站基本信息只包含中英文名称。
- **装饰列车**：从「构件库 → 装饰 → 列车」选择车型、自定义尺寸和编组，点击轨道放置。提供地铁 A / B / C1 / L、市域 C / D、香港 R-Train 预设；每组 1–12 节、1–4 组重联，保留各组驾驶室和连接。列车按实际尺寸显示，自动对齐轨道方向与楼层；长度不足、宽度不足或与已有列车重叠时显示红色且禁止落位。轨道两端各留 0.5 m、列车之间留 1 m，宽度包含模型细节及余量。放置后可独立选择、隐藏、复制、删除、拖动或调整沿轨道偏移；改变编组和轨道尺寸会重新校验。列车跟随所属轨道位置、旋转、线路颜色和楼层，删除轨道同时删除其列车，均支持撤销。旧轨道列车自动转为独立对象；旧方案超长列车保留参数并标红，需调整编组或延长轨道。取值口径与 R-Train 门数示意说明见 [车型来源说明](docs/train-presets.md)。
- **全部楼层对齐**：全部楼层模式下可直接放置构件或绘制区域，放置栏 / 钢笔工具栏可选操作楼层；默认虚化其他层的构件、填色和标记，可通过「虚化其他层」开关恢复。换层保留当前操作，楼梯起点确定后当前操作层随终点层切换。虚化仅用于编辑辅助，不改变方案显隐或导出设置。
- **观察**：3D 示意、分层平面、等轴测、俯视、正立面；拖动旋转、右键平移、滚轮缩放。平面模式将连通的付费区、非付费区合并后描外围黑边，块与块之间可通行的接缝不描边；楼梯、扶梯在对应楼层的落地口，以及电梯门口自动留空。保留外围、楼梯井侧边和其他孔洞边缘，实际栏杆与屏蔽门继续独立显示；描边同步进入 PNG 导出。平面模式显示全部楼层时，各层平面会分开排列。
- **显示**：名称、文字标注、设施标记、完整标记、网格和楼层分解分别开关。「文字标注」控制独立文字；轨道箭头只由每段轨道的「显示箭头」控制，不受全局显示设置影响。关闭「完整标记」时隐藏闸机、自动扶梯和楼梯的标记，保留出口、卫生间、服务中心和无障碍电梯标记；构件模型保留。开关随方案保存并应用于 PNG 导出。
- **文件管理**：点击顶部方案名称打开「我的车站方案」，支持新建空白车站 / 上海火车站示例、搜索、重命名、另存副本、切换方案和回收站恢复。每个方案独立保存，文件名称与车站名称分开设置；新建、载入示例和打开 JSON 均保留原方案。切换前自动保存，切换后清空撤销记录，刷新恢复上次打开的方案。标题旁的小点表示未保存，存储失败时会提示并保留当前编辑。
- **方案**：自动保存和「保存方案」按钮保存到当前浏览器；文件管理中的「下载 JSON」及「导出方案 → 保存可编辑方案」可下载可编辑文件。支持撤销/重做、JSON 导入导出及当前视角 PNG 导出。PNG 按当前画布的位置、样式、SVG 图标和名称/标记开关生成 2 倍分辨率图片，保留标题、图例和比例尺，省略悬浮编辑工具。导出面板中的「底部文字标注」可选附加线路、构件数量等方案信息，默认关闭。

- **连续放置**：新建构件、标记、文字或列车时，按住 `Shift` 完成落位会保留工具和上一件的参数，继续放下一件。两点构件重新选择起终点，楼梯、扶梯和电梯保留连接楼层及选层顺序；曲线轨道用 `Shift+Enter` 或按住 `Shift` 点击「完成轨道」后重新选起点。列车继续检查空间与占位，每件对象独立生成并可单独撤销。松开 `Shift` 后完成下一件会退出，`Esc` 随时取消当前草稿；已有列车重新定位和文字锚点取点仍为单次操作，区域钢笔保留原有 `Shift` 约束 / 多选行为。

快捷键：`Shift` 连续放置、`Esc` 取消选择 / 放置、`+`（或 `=`）上一层、`-` 下一层（支持数字小键盘，按实际标高排序，到顶 / 底停止；放置楼梯或电梯时保留第一点并同步连接楼层，输入框及弹窗中不触发换层）、`V` 选择、`T` 文字、`G` 移动构件、`H` 平移、`F` 适应画布、`Delete` 删除、`Ctrl+Z` 撤销、`Ctrl+Shift+Z` 重做、`Ctrl+S` 保存、`Ctrl+Shift+S` 另存副本、`Ctrl+N` 新建、`Ctrl+O` 打开 JSON、`Ctrl+K` 搜索。

方案库保存在当前浏览器的 `localStorage`，包含回收站；下载 JSON 可备份或转移设备。清理浏览器网站数据会清除方案库，重要设计请下载备份。原来的单方案自动迁入方案库并保留旧数据备份。当前方案格式为 v4，旧版轨道文字首次打开时自动拆成独立文字，保留内容、位置、楼层、颜色和朝向；之后不再重复生成。旧版站台和站厅转换为填色区域，旧出口通道转为非付费区，出口标记移至原通道末端；已有付费区和员工区域不会被覆盖。删除楼层会合并填色与构件，重叠处保留目标层填色。默认图为可编辑示意方案，并非实测工程图。

曲线上的列车逐节沿实际路径排列并转向，车间连接随之调整，支持反向与重联。按实际弧长、宽度及已有列车占位校验编组，不限制示意轨道的弯曲半径。PNG 导出保留曲线和色带，省略选框、文字编辑框及路径控制点。
